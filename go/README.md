# WriteCodeEveryDay

这是一个符合Go标准项目布局的项目脚手架。

## 项目结构

```
.
├── README.md
├── go.mod
├── cmd/
├── internal/
├── pkg/
├── api/
├── configs/
├── docs/
├── scripts/
└── util/
```

## 目录说明

- `cmd/` - 主要的应用程序入口点
- `internal/` - 私有应用程序和库代码
- `pkg/` - 可以被外部使用的库代码
- `api/` - API相关代码
- `configs/` - 配置文件
- `docs/` - 项目文档
- `scripts/` - 脚本文件
- `util/` - 工具函数
